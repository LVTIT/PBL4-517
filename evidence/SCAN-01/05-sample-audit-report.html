22/tcp: FILTERED80/tcp: FILTERED443/tcp: FILTERED3000/tcp: FILTERED5432/tcp: FILTERED8080/tcp: FILTERED

🛠️ Hướng dẫn Khắc phục trên AWS EC2 Security Group:

  1. Đăng nhập vào AWS Management Console → Vào dịch vụ EC2 → Chọn Security Groups.
  2. Tìm Security Group đang gắn với máy chủ EC2 (Mục tiêu 127.0.0.1).
  3. Chuyển sang tab Inbound rules → Nhấn nút Edit inbound rules.
  4. Xóa bỏ hoàn toàn các rule mở cổng cơ sở dữ liệu (5432, 3306, 6379, 27017) hoặc backend thô (3000, 8080) có Source là 0.0.0.0/0.
  5. Đối với port 22 (SSH): Chỉ cho phép IP tĩnh cụ thể của người quản trị (Dạng x.x.x.x/32), tuyệt đối không mở cho mọi IP.
  6. Lưu lại cấu hình và chạy lại Scanner để kiểm chứng trạng thái cổng đã chuyển thành FILTERED.
